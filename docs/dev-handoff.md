## 文件职责和字段关系

- `apps/web/src/`：英文 React / Ant Design 界面，房源主入口与需求、详情、客户比较交互。
- `shared/types.ts`：保持模板 snake_case 字段；从显式 ID 派生客户和房屋，不用挂牌 ID 猜房屋身份。
- `shared/matching.ts`：确定性硬条件过滤、面积单位换算、排序与条件解释，供所有候选入口复用。
- `shared/assistant.ts`：`AssistantAdapter` 接口；当前规则实现用于结构化草稿，没有声称已接入大模型。
- `shared/pricing.ts`：只把合格记录分类到同屋历史或可比成交；不做精确估值。
- `apps/api/ingest.mjs`：按冻结 schema 读取/校验 CSV 或 JSON，隔离不合格记录及其依赖。
- `apps/api/server.mjs`：Node 原生 HTTP、只读 GET、本机绑定、每次请求重新读取。
- `data/demo/`：可替换的完全虚构样例及生成脚本；`data/incoming/`、`data/private/` 为不进 Git 的真实输入位置。

数据契约使用五张表，区分以下实体与关系：

| ID / 表 | 含义与关联 |
|---|---|
| `client_id` / `requirement_id` | 脱敏客户可以有多份需求；不能以电话或邮箱作为客户 ID |
| `property_id` / `listing_id` | 房屋身份与挂牌身份分开；房屋 ID 仅在证据可靠时填写，允许一房多挂牌 |
| `snapshot_id` / `listing_snapshots` | 一次挂牌观察一个稳定快照 ID；同挂牌更新增加快照 |
| `transaction_id` / `transactions` | 来源中的交易记录，不等于房屋身份 |
| `link_id` / `listing_transaction_links` | 显式关联挂牌与交易；标明 exact_property、comparable 或 unresolved |
| `case_id` / `match_reference` | 产品人工期望结果，引用需求、挂牌及合格价格关联；不作为助手输出 |

金额、币种、面积值/单位/口径、来源、采集时间、核验和许可分别保留。多值 CSV 字段用 `|`，应用内为数组；空值为 null，不用 0 代替 Unknown。

## 样例性质与覆盖

默认 `data/demo/dataset.json` 为 **10 个挂牌 / 11 个快照、6 个交易、7 个关联、6 份需求、8 条人工参考**；全部 `data_kind=demo`，来源 `Synthetic demo fixture` / `DEMO-*`。其中的 verified、approved、confirmed 仅表示演示样例的技术状态，不代表产品或真实业务核验。

- `DEMO-L-001`：虚构 Marina ready 两居，最新 AED 2,450,000、1,280 sqft built_up；旧挂牌快照 AED 2,550,000。
- `DEMO-R-001`：虚构 Marina apartment / ready / 至少两居、AED 2.2m–2.8m、至少 1,100 sqft built_up，候选 `DEMO-L-001/002`。
- `DEMO-LINK-001`：虚构同屋成交；`DEMO-LINK-002`：不同房屋可比；`DEMO-LINK-003/005`：抵押/部分份额排除案例。
- `DEMO-L-007` 无价格，`DEMO-L-008` 无面积，`DEMO-L-009` 下架但未断言成交，`DEMO-L-010` 使用 USD。
- `DEMO-R-004` 无匹配，`DEMO-R-006` 信息不完整；`DEMO-R-001/002` 可对应同一 `DEMO-L-001`；`DEMO-L-005/006` 无成交历史。

样例是覆盖交互的测试材料，不是 BHHS 客户事实、真实估价或已确认产品规则。EnerMech 仅作为工程和交互参考，没有继承油服字段、Project Gate、固定导出字段数或页面数量限制。

## 产品接入与数据安全边界

填写格式沿用 [数据契约](data-contract.md)、[模板说明](../data/templates/README.md)、[schema](../data/templates/schema.json) 和 [字段字典](../data/templates/field_dictionary.csv)。详细步骤见 [导入指引](import-guide.md)。不修改冻结表头，不让产品覆盖演示目录。

```powershell
$env:BHHS_DATA_DIR = 'data/incoming/批次名称'
npm run dev
```

目录内放五份契约 CSV，或直接指定五表 `dataset.json`；首版不直接导入 XLSX。缺少某张表时该表为空并提示，其他合格表继续加载。环境变量变化需重启；替换文件后刷新数据。解析错误会返回安全错误，不沿用旧缓存，不泄露原始隔离字段值。

校验包括：必填、类型、枚举、稳定 ID 唯一、完整日期和时区、有限非负数字、预算范围、金额币种和面积单位/口径。真实数据必须 verified / approved，人工验收参考必须 confirmed；不合格行及跨表依赖级联隔离。

**最新快照规则：**先看全部输入的 `captured_at`，再判断最新记录能否接受。最新被隔离或时间顺序无法确认时，同一挂牌全部暂扣，旧 active 不会回退成当前库存。旧快照的一般字段错误不阻止合格最新快照。

**价格证据规则：**同屋历史要求匹配的稳定 `property_id` 和两侧来源引用；同楼或同面积不足以建立身份。两侧已知同一 `property_id` 却标 comparable 时隔离，不自动改分类。价格参考要求 sale / whole_unit、金额日期明确、来源和关联已核验、使用允许、币种及面积口径可比；抵押、租赁、赠与、打包、部分份额或 unresolved 不用于住宅出售价格对比。
