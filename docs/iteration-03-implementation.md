## 实施约定

- 首页直接展示现有规则助手和需求审核；房源库保留选客及审核入口，移除重复的新需求自然语言入口。登录位于顶部，首页、房源、客户、报告采用同一导航。
- 房源列表独立显示地区和类型，将卧室与 sq ft 面积放在一组。手动筛选新增面积上限及列头排序；不增加 Search 按钮。面积上限只属于当前搜索，不静默新增产品 CSV 字段，审核原文中的上限继续按现有规则提示。
- AED 为演示搜索币种，sq ft 为列表及手动筛选单位；不将非 AED 金额直接改标。审核需求和价格证据保留原始币种/单位以免失真。缺字段与无历史测试样本保留，不为了“补齐”而伪造接收批次。
- 用 Username / Sales ID 演示身份，私有副本的保存范围为批次版本 + Sales ID。切换身份同步清除页面选择和详情上下文；公司导入样本共享。旧无归属浏览器副本保留原键，退出身份后以 Unassigned browser review 查看，不自动归属第一位销售。
- 该身份是本机演示分区，不是服务器认证。已有导入契约没有公司/私有权限字段，真实客户权限需另行接入，不能声称演示登录能保护真实客户资料。
- 报告使用两个 Tab，复用价格证据与成交图。看房行为另存当前销售的本机版本，不写回客户原文。显式示例按钮可生成明确虚构的行为；规则统计说明样本与依据，不称已训练 AI，不将到访次数直接当成偏好或成交意愿。

## 继续待确认的业务事项

`ready/off_plan` 继续表示竣工状态，`active/withdrawn/sold` 表示挂牌状态；保留现有状态分组及按客户去重口径。合同日、登记日按已有 `date_basis` 分开，不把登记日改称成交日。新增总数说明与可追溯名单，但不凭文档改写匹配算法或业务字典。

客户面积口径、精确户型/最低值、预算下限与费用、购买日期、人工参考理由与真实来源许可仍统一由用户补充。原 15 条人工参考维持 draft；既有接收数据和逐条报告保持忽略。本清单中的历史“跳转异常”按实际复现和新验收记录，不预先当作已验证缺陷。
