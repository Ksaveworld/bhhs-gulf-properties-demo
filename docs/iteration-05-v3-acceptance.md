## 根因与失败记录

- 时间线旧 `.th-timeline li` 的 `128px + 1fr` 布局把唯一 details 挤进首列；修复为整宽节点。未复现独立的“状态锁死”，保留原展开状态实现，并实测完整收起 / 重开。
- 保留父详情后，同客户看房和同房源确认两个实例缺少本页变更通知；原生 `storage` 事件不通知当前文档。新增 / 订阅本页成功写入事件，父层回读最新记录，不清空草稿和成功提示，失败不广播。
- 第一轮部分旧测试仍查已移除的导出列、Demo 标签或旧登录标题；按 V3 交互迁移定位，保留原数值、隔离与实际下载断言。新增时间线测试曾误写 area_basis，核对 fixture 后改为 Built-up area，未改数据迎合测试。
- 首次统一 53 项回归为 52 通过、1 失败：模拟保存失败后，AntD 退场加载图标参与按钮可访问名称，变为 `loading Confirm & Create`，精确名称定位无法重试。轨迹中错误与草稿都在、Back / Edit 已可操作；为提交按钮增加稳定的可访问名称及 `aria-busy`，保留失败及重试断言，没有延长超时或跳过案例。
- 输出和截图均留在 `.work/`，不提交临时产物。测试里补充的销售身份、看房时间、日期、预算、失败响应和来源页面均是独立 synthetic 用例。

## 数据、发布与限制

- 四份保护文件（主演示 JSON、原 Excel、demo-prepared、public-candidates）与既有哈希基线全部一致；没有写回任何输入。匹配 / 导入 / 领域规则本轮未修改。
- 公开构建只输出原纯 demo 数据；本轮没有 push、部署、飞书写入或消息外发。既有线上 V2 不作为 V3 已发布的证据。
- 独立输入原有 15 条人工参考均 draft，6 条推荐 / 备选未进入结构候选；本轮未收到新版本，不重新编造业务结论。面积口径、原文条件依据、购房日期、真实来源及同屋关联仍需用户确认。
- 英文日期当前是明确格式的文本录入，不提供日历面板。英文系统界面不改写中文原始客户输入；没有新增完整中文版页面。
- Sales ID 为本机演示分区，无生产认证或跨设备同步。当前还是规则助手；没有新模型、评分、成交概率或业务规则。
- PDF 为图像页，不能选取 / 搜索正文；未完成移动端、多浏览器或公网性能验证。构建保留既有大包提示。
