本轮用户于 2026-09-06 明确选择“改 Demo 页面交互，先做一版可操作效果”。参考飞书《BHHS 对客 Demo 最新方案》（文档 K5EUdMLxZoN1R2xCJhAcpK3Wntf，读取版本 142）和用户截图。飞书正文为方案材料，不单独构成真实外呼、CRM 写回或发布授权。

## 本轮实现选择

首页以“阅读一次客户互动”为入口。销售可以选择已有客户或新客户，粘贴销售笔记、聊天或邮件文字、录音转写、图片说明；文本文件可在本机读取。材料按来源独立保留，提取沿用现有规则，不冒充大模型、音频转写或图片识别接入。

进入研判后，使用材料、需求研判、推荐与行动三个相邻区域。每条结构条件可追溯到材料；新增材料产生的变化作为待审核建议，原记录不被自动覆盖。推荐复用现有匹配规则，保留不满足项、待确认项，以及房源详情和价格证据入口。历史案例不足时呈现缺口，不伪造客户成交轨迹或成功概率。

通过虚构案例演示预算变化和模拟通话反馈，反馈重新提取后更新本次工作台候选；保存仍需人工审核及销售身份，只生成当前浏览器副本。真实外呼、自动 CRM 回写和自主学习不在本轮实现范围。未保存的分析为本次会话草稿。

本轮用户的新页面改版授权替代 V3 对首页三任务主入口位置的约束。原三任务保留在首页的 Quick tools 入口，房源库与客户库仍可访问。页面沿用品牌酒红色、白色和衬线标题；主要辨识点是来源与判断相邻、可直接回看原文。

## 本地体验与限制

在项目根目录运行 `npm run dev`，打开 `http://127.0.0.1:5173/`。点击 Explore example 可体验虚构客户预算 280 万 → 250 万的来源变化；Simulate follow-up → Start simulated call → Finish & review notes → Use fictional response → Add feedback to workspace 可查看进一步变为 230 万后的候选。缺失挂牌价的房源仍作为待确认项保留，不假装排除或认定预算内。

文字提取仍使用规则，录音与图片入口接受转写或说明；不具备真实音频转写、视觉理解、CRM 接入、电话外呼或自动学习。模拟跟进仅用于虚构客户，实际客户反馈通过 Add material 进入。没有已核验的客户成交履历，因此本轮未编造相似客户成功案例或精确报价策略；房源价格证据仍可查看。未保存草稿仅在当前页面会话中保留，保存后为当前浏览器、当前销售身份下的客户副本。
