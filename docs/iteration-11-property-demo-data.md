# 推荐房源模拟数据补全

依据：用户指出推荐房源打开后价格证据和潜在客户内容不足，并明确允许补充模拟数据。本轮延续同一 Demo 的修改、提交及上线授权。

## 数据与交互

- 三套房源保持现有名称、地址、户型与挂牌价：Frond N 22.5m、Frond K 17.8m、Sector E 23m AED。
- 每套新增模拟面积、可用日期、上架日期、配套设施与稳定的模拟房屋标识；房源状态为 Active、Ready。
- 每套 2 笔本房历史成交、3 笔独立房源可比成交。历史以同一模拟房屋标识关联，可比使用独立标识；币种、面积口径、来源、关联核验仍通过原有规则，不放宽真实数据门槛。
- Frond N 可比价格沿用原价格分析的 20.8m、21.6m、22.4m；日期、具体面积和其他新增字段均为本轮模拟设定。全组情景时间固定为 2026-03-12，与原客户演示时间线一致。
- 6 位模拟客户具备预算、位置、户型、面积、时间窗、必备条件和来源记录。每套展示对应位置的客户组：1 位条件满足、1 位预算及偏好需确认；不生成成交概率或客户资产。
- 所有模拟数据集中在 `shared/prototype-listings.ts`。仅在 demo 模式补入运行时数据，不写入原始输入，不改变 product 模式；重复加载不增加重复记录。
- 房源库保留原列表，推荐房源详情、客户详情及报告使用同一份补充数据。模拟客户可进入详情，再打开对应推荐房源并逐层返回。
- 新房源 Drawer 和模拟客户详情显式标记演示内容。PDF／Word 保留演示声明与 `SIMULATED:` 来源编号。
