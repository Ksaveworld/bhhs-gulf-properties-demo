# 演示报告与本机看房记录

Reports 提供 **Property scan report** 与 **Client profile report** 两个入口。房屋报告复用已有挂牌、同屋成交及可比成交组件，原始币种、面积口径与合同/登记日期不混用。无历史显示空态，不补造交易；仍可通过详情或成交控件查看来源。

## 客户报告

登录演示 Sales ID 后可选当前可见客户及其独立需求，查看预算、地区、物业类型和原文。销售在 **Add a viewing record** 填写房源、看房时间、反馈和明确偏好标签，成功保存后更新时间线、次数和规则汇总；刷新、重开同一浏览器配置/地址/批次版本/销售身份后恢复。未填写的反馈不推断为正面。

| 内部字段 | 含义 |
|---|---|
| `record_id`、`client_id`、`listing_id`、`sales_id` | 独立看房记录及其客户、挂牌与记录者身份 |
| `viewed_at`、`created_at` | 销售输入的看房时间与浏览器记录时间，均保存 UTC ISO；表单注明本机时间，时间线按浏览器本地时间显示；来源中的 Captured 为 UTC 记录时间 |
| `feedback`、`feedback_signal` | 销售原文与主动选择的 positive / mixed / negative / not_recorded |
| `preference_tags` | 仅主动勾选的地区、类型或面积偏好；正面到访反馈不自动生成标签 |
| `source_kind`、`source_ref` | sales_entered 或 fictional_example，来源为本机销售记录 ID 或虚构示例 ID |
| `data_kind` | 涉及虚构客户/房源为 demo；真实资料的人工录入为 sales_recorded，界面继续标为未核验 |

存储版本为 1，键包含批次范围和 Sales ID。追加写入检查修订号、关联、字段及写后回读，失败保留表单并提示。删除该客户最后一份可见需求后，其看房记录不可见，但原存储不被连带抹除；仍有同客原件或其他副本时继续显示。之后另加记录不会覆盖被暂时隐藏的记录。此功能不写回原有五表，也不进入命令行人工案例对照。

## 汇总口径与演示假设

规则汇总分别计数：该地区/类型/面积的到访、明确偏好标签、整次到访的正面反馈，并列出计入的记录 ID。观察到访不等于偏好，正面反馈不证明客户喜欢所有维度。没有训练或调用模型，不推断资产、购买力或成交概率。

同预算客群使用当前可见客户中**同币种、两个预算边界完整且区间有交集**的其他客户。只用单份需求判断交集，同一客户多份需求不拼接且按客户去重。少于两位其他客户或两次记录时显示观察不足。这个阈值是 Demo 的保守展示选择，不是已确认业务规则；报告列出所用需求、客户数和记录数。

**Load fictional viewing examples** 必须主动点击，最多为前三位可见 demo 客户与前两套 demo 房源追加六条明确虚构的记录；不为真实客户生成示例。每条都标记 Fictional example，来源、看房时间和反馈属于交互演示，不代表客户真实到访。原始需求与人工 draft 不变。该按钮不能代替用户对业务假设、真实证据或授权的确认。

演示身份仅用于本机界面分区，不是正式认证；同一浏览器使用者可以选择其他 Sales ID 或检查本机存储。当前没有服务器备份、跨设备同步或真实客户权限管理。真实业务数据需另行提供授权、访问范围和看房记录依据。
